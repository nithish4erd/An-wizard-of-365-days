# A WIZARD EXPERIENCE OF 365 DAYS — V4

A GitHub Pages-ready progressive web app prototype combining a 365-day magical academy story, daily productivity missions, character attributes and optional games.

## Included in V4
- Original 365-day Aurelion story data and 12 monthly arcs preserved from V3.
- Eight editable daily primary tasks:
  1. Early Wake-up
  2. Daily Exercise
  3. Avoid Bad Habits
  4. Evening Study
  5. Develop a Skill
  6. Avoid Using Phone
  7. Make Yourself Tidy & Happy
  8. Maintain a Sleep Cycle
- Three editable subtasks under each primary task (24 total).
- Complete a primary task to earn its attribute XP and wizard XP.
- Story choices unlock after all eight primary tasks are completed for the current day.
- Character attributes: Vitality, Strength, Discipline, Intelligence, Expertise, Self-Control, Well-being, Confidence and Recovery.
- Spell Duel Arena, Potion Crafting, Dungeon of Knowledge, Academy Tournament, Rune Memory and Logic Chamber.
- One permanent companion choice (Dragon, Owl or Fox).
- Personal Chronicle, daily reflection, milestone history and Future Self checkpoints.
- Local browser save, JSON export/import, light/dark theme and offline PWA cache.

## Publish on GitHub Pages
1. Create a **new** GitHub repository. Keep the old A COLLEGE OF 1000 DAYS repository untouched as your backup.
2. Extract this ZIP.
3. Upload the contents of the extracted folder to the root of the new repository (so `index.html` is at the repository root).
4. Commit to the `main` branch.
5. Open **Settings → Pages**.
6. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
7. Open the published URL once while online. In Chrome, use **Add to Home screen** or **Install app** if offered.

## Important notes
- This is a PWA, not a native Android APK. It has not been verified on your Android device.
- Progress is stored in this browser on this device. Use Export my records regularly for backups. There is no cloud sync.
- The app contains fictional story characters and fictional academy events. Your personal productivity records are stored separately in browser data.
- This is a prototype build. Games are lightweight browser mini-games; there is no multiplayer or server-side account system.
- The story text data is preserved from the earlier build; this update does not claim every one of the 365 episodes has been individually hand-written and polished.
